구글 검색 지도 자동 동기화 v1.0

설치
1. ZIP 압축 해제
2. Chrome 주소창에 chrome://extensions 입력
3. 개발자 모드 켜기
4. '압축해제된 확장 프로그램을 로드합니다' 클릭
5. google-map-sync 폴더 선택

사용
- www.google.com 또는 www.google.co.kr에서 아무 검색어나 검색하면 네이버지도와 카카오맵 탭이 자동으로 열립니다.
- 다음 검색부터는 기존 지도 탭을 재사용합니다.
- 구글 검색 탭은 그대로 유지합니다.
- 별도 검색창이나 버튼은 없습니다.

주의
- 지도 사이트 로딩에는 시간이 걸릴 수 있습니다.
- Chrome 종료 후 세션이 새로 시작되면 지도 탭을 다시 만들 수 있습니다.
- 검색어가 지도 사이트에 전달됩니다. 회사 보안 정책을 확인하세요.
- Chrome의 다른 구글 국가 도메인(예: google.co.jp)은 현재 지원하지 않습니다.
